# TRLC Project

Official fundraising platform for **The Resurrected Life Conference (TRLC)**, organized by **The Resurrected Church**.

## Features

- Responsive Landing Page
- Secure Online Giving
- Live Campaign Progress
- Firebase Firestore
- Paystack Integration
- Netlify Serverless Functions
- Gallery
- Testimonials
- YouTube Integration

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Firebase
- Netlify
- Paystack
