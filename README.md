# 🏗️ Development Structure & Technologies

**Designed & Developed by Daniel Ukpai C (DceeTechBro)**

TRLC was built using a modern frontend architecture with Firebase-powered backend services.

The project demonstrates practical experience in building responsive, user-focused digital experiences using modern web technologies.

---

## Frontend Structure

The project uses:

- **HTML5** — Semantic structure, accessibility, and SEO-friendly markup
- **CSS3** — Responsive layouts, reusable components, design system, and animations
- **JavaScript (ES6+)** — Interactive features, DOM manipulation, and application logic

---

## CSS Architecture

The styling is organized into reusable modules:

```text
CSS/
├── style.css          # Global styles and design system
├── components.css     # Reusable UI components
├── responsive.css     # Mobile and tablet responsiveness
├── give.css           # Donation page styling
└── admin.css          # Dashboard styling
```

---

## JavaScript Architecture

Functionality is separated based on purpose:

```text
JS/
├── app.js             # Main website interactions
├── firebase.js        # Firebase connection
├── payment.js         # Donation functionality
├── testimonials.js    # Testimonial handling
├── admin.js           # Dashboard logic
└── admin-auth.js      # Admin authentication
```

# 🔥 Firebase Integration

The project uses Firebase services for backend functionality:

### Firebase Authentication
- Secure admin login
- Protected dashboard access

### Cloud Firestore
- Stores campaign information
- Enables dynamic fundraising updates

### Firebase Hosting
- Production deployment
- Secure HTTPS hosting
- Fast content delivery
